## 4. P0 — Fix React Error #310

Đây là lỗi ưu tiên cao nhất và là release blocker.

### Hiện tượng

Từ Folio Quick Preview, khi bấm "Chi tiết đầy đủ", website hiển thị:

"This page couldn’t load"

Browser console xuất hiện React Error #310.

Lỗi đã được tái hiện khi chuyển đến:

- /repositories/1
- /repositories/188

Trang openclaw có thể mở được sau khi reload trực tiếp.

### Tài liệu tham khảo

https://react.dev/errors/310

https://react.dev/reference/rules/rules-of-hooks

### Yêu cầu

- Tái hiện lỗi trên trình duyệt.
- Sử dụng development build và stack trace để xác định component gây lỗi.
- Kiểm tra Rules of Hooks.
- Kiểm tra conditional rendering.
- Kiểm tra early return.
- Kiểm tra custom Hooks.
- Kiểm tra loading, error và data-ready states.
- Kiểm tra route transitions.
- Kiểm tra Folio Quick Preview.
- Kiểm tra trang Repository Detail.
- Kiểm tra việc tái sử dụng component giữa các repository.

Đây là các hướng điều tra, không được mặc định một trong số đó là nguyên nhân khi chưa kiểm chứng.

Xác định root cause thực tế trước khi sửa.

Không sử dụng workaround như reload toàn bộ trang, bắt lỗi rồi bỏ qua, tắt tính năng Folio hoặc thay đổi navigation chỉ để che giấu lỗi.

### Regression testing

Sau khi sửa, kiểm tra:

- Folio → Chi tiết đầy đủ.
- Repository grid → Repository detail.
- Repository list → Repository detail.
- Featured repository → Repository detail.
- Truy cập URL trực tiếp.
- Reload trang chi tiết.
- Browser Back/Forward.
- Chuyển liên tiếp giữa nhiều repository.
- Loading, empty và error states.
- Desktop và mobile.
- Light/Dark mode.

Kiểm tra tối thiểu các repository đã phát hiện lỗi và một số repository khác có dữ liệu khác nhau.

Đảm bảo không còn React #310 trong các luồng đã kiểm thử.

Bổ sung regression test tự động nếu test infrastructure hiện tại hỗ trợ.
